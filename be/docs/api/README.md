# FocusBuddy API Documentation

Welcome to the FocusBuddy API documentation. This backend follows a structured layered architecture (Router -> Schema -> Service -> Repository -> Model -> DB).

## Modules

1. [User Management](user-api.md)
   API for managing users, authentication, student profiles, and preferences.

2. [Academic Management](academic-api.md)
   API for managing academic reference data like Universities, Majors, Curriculums, Courses, and Academic Terms.

3. [Learning Activity Management](learning-api.md)
   API for managing user learning activities including Study Sessions, Study Tasks, and Learning Goals.
